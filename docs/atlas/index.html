Plate II / Illustrative

Routing lab

GRAFT routes agent tasks by capability across heterogeneous devices. This lab is a deliberately small, deterministic sketch of that idea. Change what the task needs, or close the remote gate, and watch the route and every reason update.

  1. 1Keep only devices that offer the capability the task needs.
  2. 2Drop remote devices unless remote execution is allowed.
  3. 3Prefer the first eligible local device, then the first eligible remote one. Otherwise hold the task.

Illustrative only. Sample devices and fixed rules. No timing, cost or benchmark data, and nothing runs on a real device or server.

    ACM CAIS 2026

    GRAFT: gRPC-Routed Agent Framework for Tasking in Edge and Personal Devices

    Chinmay Shringi, Alon Hillel-Tuch, Sariya Rizwan

    A runtime for agent tasks on edge and personal devices. It routes work by capability across CPU, GPU and NPU targets over sessioned gRPC and keeps execution inside safety bounds.
